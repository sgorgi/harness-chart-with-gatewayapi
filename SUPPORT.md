# Support

This repository is an independent community project and is provided on a
best-effort basis without a support-level agreement.

Use GitHub Issues for problems that can be reproduced in the overlay itself.
Sanitize values and rendered manifests before sharing them. Never post
credentials, private keys, access tokens, internal domains, customer data, or
production configuration.

For Harness Platform product behavior, licensing, registry access, or
commercial support, contact Harness through the support channel associated
with your subscription. For Envoy Gateway, Gateway API, Kubernetes, or Cilium
behavior, use the corresponding upstream project's support channels.

kind. See [`LICENSE`](LICENSE), especially Sections 7 and 8, for the complete
warranty disclaimer and limitation of liability.
